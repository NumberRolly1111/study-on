# Study On

Сайт школы английского языка Study On (Астана, пр. Кабанбай батыр, 56Б).
Чистые HTML, CSS и JS без сборки и зависимостей.

## Структура
- `index.html`: страница
- `css/style.css`: фирменный стиль (графит, белый, жёлтый)
- `js/main.js`: меню, анимации, мини-тест уровня, слайдер отзывов, лайтбокс, форма → WhatsApp
- `assets/`: фото и favicon

## Что уточнить у школы
- Цены и расписание групп (на сайте «уточняйте в WhatsApp»)
- Часы работы, полный список уровней, реальные тексты о методике

## Публикация (GitHub Pages)
Settings → Pages → Deploy from branch → `main` / root.
Свой домен: файл `CNAME` с доменом в корне и DNS-запись у регистратора.
