# Study On

Сайт школы английского языка Study On (Астана, пр. Кабанбай батыр, 56Б).

- Один статичный файл `index.html`: без сборки и зависимостей
- Заявки уходят в WhatsApp (+7 700 825 03 88)
- Данные взяты со страницы 2ГИС: https://2gis.kz/astana/firm/70000001118203373

## Что нужно уточнить у школы
- Список курсов и цены (сейчас «Стоимость уточняйте»)
- Часы работы, логотип, реальные фото

## Публикация
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
Свой домен: добавить файл `CNAME` с доменом и записи DNS у регистратора.
