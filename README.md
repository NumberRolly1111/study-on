# Study On

Сайт школы английского языка Study On (Астана, пр. Кабанбай батыр, 56Б).
Чистые HTML, CSS и JS без сборки и зависимостей.

## Структура
- `index.html`: главная
- `about.html`: о школе (80% практики, 1000+ учеников, галерея, как добраться)
- `courses.html`: обучение и уровни
- `trial.html`: бесплатный пробный урок и акция «Приведи друга» −25%
- `test.html`: мини-тест уровня
- `reviews.html`: отзывы
- `contacts.html`: контакты, форма, карта
- `css/style.css`: фирменный стиль (графит, белый, жёлтый)
- `js/main.js`: меню, анимации, тест, FAQ, форма → WhatsApp
- `assets/`: фото и favicon

Шапка и подвал продублированы в каждом HTML-файле. Если меняете меню, правьте все 7 файлов.

Свой домен: файл `CNAME` с доменом в корне и DNS-запись у регистратора.
